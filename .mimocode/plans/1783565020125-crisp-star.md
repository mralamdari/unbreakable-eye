# Fix: Make app work in both Docker and local mode without toggling

## Problem

Every time you switch between Docker and local mode, you have to manually change `POSTGRES_HOST` in `.env`:
- Docker needs `POSTGRES_HOST=postgres` (Docker bridge network hostname)
- Local needs `POSTGRES_HOST=localhost` (local PostgreSQL)

This is error-prone and the root cause of the "works locally but not in Docker" issue.

## Solution

Override `POSTGRES_HOST` in `docker-compose.yml` so Docker **always** uses `postgres`, regardless of what `.env` says. This way:
- `.env` keeps `POSTGRES_HOST=localhost` (works for local dev)
- Docker ignores it and forces `POSTGRES_HOST=postgres`

No more toggling needed.

## Plan

### Step 1: Add environment override to docker-compose.yml

**File:** `/home/esi/unbreakable-eye/docker-compose.yml`

Add an `environment:` block to the `fastapi` service (after `env_file: .env`):

```yaml
  fastapi:
    build:
      context: .
      dockerfile: infra/docker/Dockerfile
    container_name: unbreakable_eye_api
    restart: unless-stopped
    env_file: .env
    environment:
      - POSTGRES_HOST=postgres    # override: Docker always uses postgres service
    depends_on:
      postgres:
        condition: service_healthy
    volumes:
      - ./data:/app/data
      - ./models:/app/models
      - ./logs:/app/logs
```

The `environment:` block takes precedence over `env_file:` values in docker-compose. So even if `.env` has `POSTGRES_HOST=localhost`, the container will see `POSTGRES_HOST=postgres`.

### Step 2: Reset .env to local mode default

**File:** `/home/esi/unbreakable-eye/.env` (line 9)

Ensure it says:
```
POSTGRES_HOST=localhost
```

This is the safe default for local development.

### Step 3: Fix logs directory permissions

**File:** `/home/esi/unbreakable-eye/docker-compose.yml`

Add `user:` to fastapi service so it runs as host user (avoids permission issues with bind-mounted dirs):

```yaml
    environment:
      - POSTGRES_HOST=postgres
    user: "${UID:-1000}:${GID:-1000}"
```

### Step 4: Verify both modes work

**Docker mode:**
```bash
docker compose down
docker compose up -d --build
docker compose ps                          # all healthy
curl -s http://localhost/health            # {"status":"ok","cameras":0}
docker compose logs fastapi | grep "host=" # should show host=postgres
```

**Local mode (after docker compose down):**
```bash
docker compose down
uvicorn src.web.main:app --host 127.0.0.1 --port 8000
# Should connect to localhost:5432 (local PostgreSQL)
```

## Files to modify

1. `/home/esi/unbreakable-eye/docker-compose.yml` — add `environment:` and `user:` to fastapi service
2. `/home/esi/unbreakable-eye/.env` — ensure `POSTGRES_HOST=localhost` (reset to local default)

## What this eliminates

- No more `toggle-host.sh` needed
- No more manual `.env` edits when switching modes
- `.env` stays in local mode; Docker overrides it automatically
